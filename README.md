# 🚀 Node.js & JS APIs — Academic Lab

## 📌 About
This repository contains exercises, practical examples, and projects developed during my **Computer Science** classes. It focuses on backend concepts, web architecture, and building/consuming RESTful APIs using **Node.js** and **JavaScript**.

## 🚀 Technologies
- **Node.js**
- **JavaScript (ES6+)**
- **Express.js**
- **Postman / Insomnia**
- **Git & GitHub**

## 🧠 What I Learned
- Fundamentals of HTTP architecture and REST standards
- Route parameters, request bodies, and headers (`GET`, `POST`, `PUT`, `DELETE`)
- Middleware handling and asynchronous error management
- JSON data manipulation and response structuring

## ⚠️ Challenges
- Managing asynchronous operations (`async/await`) effectively across route handlers
- Designing clear, predictable RESTful resource endpoints
- Handling status codes and structured error responses gracefully
